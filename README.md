📌 Project Overview

This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs basic arithmetic and logical operations on two 4-bit inputs based on selection signals. It is a fundamental component of digital systems and CPU design.

⚙️ Features
4-bit inputs (A and B)
3-bit selection control signal
Arithmetic operations:
Addition
Subtraction
Logical left shift
Logical right shift

Logical operations:
AND
OR
XOR
NOT
Carry-out support for arithmetic operations
Designed using Verilog HDL
Verified using testbench simulation

🚀 Tools Used
Verilog HDL
Xilinx Vivado / ModelSim
FPGA Simulation

🎯 Applications
CPU design
Microprocessors
Embedded systems
Digital signal processing

📖 Learning Outcome
Understanding ALU architecture
RTL design using Verilog
Testbench verification
Digital system design fundamentals
